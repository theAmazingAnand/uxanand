# CarSlot UX case study

Open `index.html` in a modern browser. This is a standalone, dependency-free case-study website.

## Contents

- Gently animated product-led hero
- Sticky navigation and four-phase vertical journey rail
- Traditional UX case-study narrative: context, research, definition, design, validation, delivery, outcomes
- Visual information architecture, user flow, wireframe set, unchanged embedded product outputs, and review timeline
- Searchable/filterable library containing all 27 project outputs
- Persistent link to open the final interactive prototype in a new tab

The earlier preview in the parent `casestudy/` folder is preserved unchanged.

The product screens are presented through the supplied MacBook Pro, iMac, and iPad SVG mockups. The case-study page does not redraw or alter the application interface shown in those assets.
