# CarSlot case study — reference decision map

This document records the structural ideas adopted from the supplied references. The final experience is an original composition; no reference artwork, copy, brand system, or imagery is reproduced.

| Reference | Structural idea adopted | Where it appears |
|---|---|---|
| Global New Yorker / DD.NYC | Editorial panels, story rails, restrained motion | Hero, research narrative, artifact library |
| VOXA | Product as the focal object, layered screen depth | Hero device composition, solution showcase |
| Summit Strike Capital / Zentexx | Compact metadata, numbered chapters | Project overview and four phase introductions |
| Zentexx Case Study | Research cards and responsive device presentation | Discover phase and responsive system section |
| Brissie Estate | Full-width chapter transitions with large type | Define and Deliver chapter dividers |
| Webcare | Disciplined dark framing and restrained glow | Hero, prototype CTA, closing panel |
| SoFi Health | Editorial whitespace, premium pacing, asymmetric storytelling | Primary page foundation |
| Netflix | Cinematic opening, large phase numbers, horizontal browsing | Used selectively in hero, phase labels, artifact library |
| Held Cinematic Grid version | Diagram clarity and path indicators | IA, user flow, progress rail |

## Guardrails

- CarSlot content, evidence, and product states remain the source of truth.
- Warm white and black provide the foundation; CarSlot orange is used only for active paths and calls to action.
- Motion is confined primarily to the hero and is deliberately slow.
- The complete narrative remains scrollable, printable, keyboard accessible, and understandable without animation.
- Research limitations are shown beside findings rather than hidden in footnotes.
